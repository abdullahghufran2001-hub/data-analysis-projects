# 🛒 E-Commerce Sales Analytics Dashboard

An end-to-end **E-Commerce Sales Analytics project** built using **Python, Pandas, Plotly, and Excel** to analyze sales performance, profitability, products, customers, cities, orders, and monthly business trends.

---

## 📌 Project Overview

This project analyzes an **E-Commerce sales dataset** and converts raw transactional data into meaningful business insights.

The analysis focuses on:

* 💰 Sales Performance
* 📈 Profit Analysis
* 📦 Product Performance
* 👥 Customer Analysis
* 🏙️ City-wise Sales
* 🧾 Order Analysis
* 📅 Monthly Sales Trends
* 📊 Quantity Distribution
* 🔍 Sales vs Profit Relationship

The project also generates **cleaned data** and an automated **Excel summary report**.

---

## 🛠️ Technologies Used

* 🐍 Python
* 🐼 Pandas
* 📊 Plotly
* 📗 Excel
* 🔧 OpenPyXL

---

## 📂 Dataset

The project uses an E-Commerce Excel dataset containing transactional sales information.

### Dataset Columns

| Column             | Description             |
| ------------------ | ----------------------- |
| `Order ID`         | Unique order identifier |
| `Order Date`       | Date of the order       |
| `Sales Amount`     | Sales/revenue generated |
| `Profit`           | Profit generated        |
| `Quantity`         | Number of units sold    |
| `Product Category` | Product category        |
| `Product Name`     | Product name            |
| `City`             | Customer/order city     |
| `Customer Name`    | Customer name           |

The project also creates a derived:

**`Month`** column from `Order Date` for monthly analysis.

# 📊 Key Performance Indicators

The project calculates four major KPIs.

### 💰 Total Sales

Total sales generated across all transactions.

```python
total_sales = df['Sales Amount'].sum()
```

### 📈 Total Profit

Total profit generated from all transactions.

```python
total_profit = df['Profit'].sum()
```

### 📦 Total Quantity

Total number of products/units sold.

```python
total_quantity = df['Quantity'].sum()
```

### 🧾 Total Orders

Total number of unique orders.

```python
total_orders = df['Order ID'].nunique()
```

# 📈 E-Commerce Analysis

## 1. Category-wise Sales

Analyzes total sales generated by each **Product Category**.

**Visualization:** Bar Chart

This helps identify the categories contributing the most to overall revenue.

---

## 2. Category-wise Profit

Analyzes total profit generated by each product category.

**Visualization:** Bar Chart

This provides a comparison of category-level profitability.

---

## 3. City-wise Sales

Analyzes sales distribution across different cities.

**Visualization:** Pie Chart

This provides a geographical view of the E-Commerce business.

---

## 4. Top 10 Products by Sales

Identifies the **Top 10 Products** based on total sales.

**Visualization:** Bar Chart

This helps identify the products generating the highest revenue.

---

## 5. Monthly Sales Trend

The project extracts the month from the order date:

```python
df['Month'] = df['Order Date'].dt.strftime('%Y-%m')
```

Monthly sales are then analyzed to identify changes in sales performance over time.

**Visualization:** Line Chart

---

## 6. Monthly Profit Trend

Monthly profit is calculated and visualized to understand profitability trends over time.

**Visualization:** Area Chart

---

## 7. Quantity Distribution

Analyzes how product quantities are distributed across orders.

**Visualization:** Histogram

This helps understand common order quantities and purchasing patterns.

---

## 8. Sales vs Profit

Analyzes the relationship between sales and profit.

The visualization uses:

* **X-axis:** Sales Amount
* **Y-axis:** Profit
* **Color:** Product Category
* **Size:** Quantity

**Visualization:** Scatter Plot

---

## 9. Top Customers by Sales

Identifies the **Top 10 Customers** based on total sales generated.

**Visualization:** Bar Chart

This helps identify high-value customers.

# 🚀 How to Run the Project

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/abdullahghufran2001-hub/data-analysis-projects.git
```

### 2️⃣ Open the Project Folder

```bash
cd E-Commerce-Sales-Analytics-Dashboard
```

### 3️⃣ Install Required Libraries

```bash
pip install pandas plotly openpyxl
```

### 4️⃣ Update the Excel File Path

Change the file path in Python:

```python
file_path = r"C:/Users/user/Downloads/38134 (1).xlsx"
```

to the location of your dataset.

### 5️⃣ Run the Python Script

```bash
python dashboard.py
```

The Plotly visualizations will open/display, and the following files will be generated:

```text
summary_report.xlsx
cleaned_data.xlsx
```
